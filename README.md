# ThreatForge

An AI-powered Threat Intelligence Dashboard built with FastAPI, React, and PostgreSQL.

## 🚀 Features (Planned)

- IP Reputation Lookup
- URL Scanner
- Domain Reputation
- CVE Search
- Authentication
- Search History
- Interactive Dashboard
- Responsive UI

## Tech Stack

### Backend
- FastAPI
- Python

### Frontend
- React
- Tailwind CSS

### Database
- PostgreSQL (Supabase)
